# 案例:断轴双刻度径向图 (Broken Radial) —— 首个完整定制图案例

把"标签列 + 数值系列列(+可选总计列)"画成**断轴双刻度径向(极坐标)图**。
本文件记录**完整设计理由**——它是"非模板制图六步法"的示范案例。

## 设计理由(为什么这么设计)

| 决策 | 理由 |
|---|---|
| 极坐标(径向)而非直角 | 类别多(22+)、要保留"环状巡视"观感;直角堆叠图过于常规 |
| **断轴双刻度** | 数值跨 4~5 个数量级且一半为 0:单一线性轴小值不可见、单一对数轴大值顶天 → 半径分两区,内区放宽给中小值、外区压缩容纳极大值 |
| 断点**自适应**=数据对数范围中点(取整十倍) | 不同数据集(如 0.01~10 与 146~3525)自动落在两区交界附近,两区都有数据,不空区 |
| **非堆叠分组柱**(每系列一根)+ 总计深灰柱 | 堆叠按"份额"切分会把小值压成细线;独立柱让每个系列按**自身值**取长,小值可见;总计柱标总量 |
| 虚线扇区分割 | 22+ 扇区时,无引导线难以分清"哪几根柱属于哪个类别" |
| 小号 "break" 紧贴断点刻度值正下方 | 断轴处标注刻度"变了",位置贴刻度值、字体小,不喧宾夺主 |
| 三行小字中心标题 | 中心留白区放"标题/缩写",三行小字嵌进内圈,不占图面 |
| Times New Roman + STIX | 论文惯例衬线体,数学符号同风格 |
| 参考圆(10⁰ 红、10⁻¹ 橙,仅当在轴范围内) | 阈值体系(如 RQ=0.1/1);范围外不画,注记同步取舍 |

## 数据契约

| 列 | 角色 |
|---|---|
| 第 1 列 | 类别标签(点位/时间/样本),行数 = 扇区数 |
| 中间列 | 数值系列(非负;整列全 0 只留图例) |
| 最后一列(可选) | 总计;列名含 "sum" 才识别,否则不画总计柱 |

## 脚本用法

```sh
python3 ${SKILL_DIR}/scripts/chart_broken_radial.py <数据.xlsx> <输出名> ["中心标题三行|竖线分隔"]
```

- 标题缺省 `Risk|Quotient|(RQ)`;空串 `""` 无标题
- 输出 `<stem>.png`(200 dpi)+ `<stem>.svg`(路径文字);需改字把 `svg.fonttype` 改 `'none'`

## 可覆盖项

断点数值、参考阈值、配色(色板)、起始角与方向、分割线样式、中心标题文案、
break 位置字号、字体、输出尺寸/dpi。

## 专属 QA 检查点(通用清单之外)

- 完整 360°、扇区标签齐全顺序正确(默认正上方、顺时针)
- "break" 与刻度值不重叠;断点圆可见
- 全零列只在图例出现;总计柱长 = 断轴映射(总计)
- **极端小值拉宽轴向**(如 10⁻⁶ 让数据挤成环)时,询问用户是否收紧轴范围
